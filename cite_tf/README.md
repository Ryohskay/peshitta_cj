# about this directory

Use the `text-fabric` version of Peshitta OT & NT.

Gather Peshitta texts and their features to correctly prepare training data.

## Notes on "feature"

- 'book': list of chapters in format of (chapter id, book title)
- 'book@en': list of books in the dataset
- 'chapter': list of chapters in the book
- 'demcat': category of demonstrative modifier (near, far)
- 'fmhdot': ?, a binary flag to do with some orthographic feature?
- 'gn': gender of noun
- 'lexeme' / 'lexeme_etcbc' / 'lexeme_sedra'
- 'nmtyp': type of numeral, "NA" or "cardinal"
- 'ntyp': type of noun, "common", "proper", etc.
- 'nu': cardinality of a noun?

- 'prefix' / 'prefix_etcbc' / 'prefix_sedra'
- 'prtyp': type of pronoun?
- 'ps': person of verb conjugation
- 'ptctyp': verb voice, passive or active
- 'root' / 'root_etcbc' / 'root_sedra'
- 'seyame': binary flag of whether syame exists
- 'sfcontract': ?, binary flag of whether there is a suffixed enclitic/conjugation to the word?
- 'sfgn': ?, gender of suffix?
- 'sfnu': ?, number of suffix?
- 'sfps': ?, person of suffix?
- 'sp': Part of speech
- 'st': noun states, emphatic or construct
